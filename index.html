05 / THEORY

Algorithm information

Exam-ready notes for Iterative Deepening Depth-Limited Search.

What is IDDLS?

IDDLS repeatedly runs Depth-Limited Search (DLS) with increasing depth limits. It begins at limit 0, then 1, 2, 3, and continues until the goal is found or a chosen maximum limit is reached.

Working principle

  1. Set depth limit to 0.
  2. Perform depth-first search without going beyond the limit.
  3. If the goal is not found, increase the limit by 1.
  4. Repeat until the goal is found or the maximum limit is reached.

Advantages

  • Complete for finite branching factors when a solution exists within the limit.
  • Uses much less memory than BFS.
  • Finds a shallowest solution when each move has equal cost.

Limitations

  • Re-expands states at each new depth limit.
  • May be slow when the solution is deep.
  • Does not use heuristic information to guide the search.

Properties

Search typeUninformed search
Time complexityO(bd)
Space complexityO(bd)
CompletenessYes, if the solution is within the depth limit and branching factor is finite
OptimalityYes, when every move has the same cost
Evaluation functionNo heuristic; search is guided by depth limits

Here, b is the branching factor and d is the depth of the shallowest solution.
